# 🚀 Devyssey

### Aplicação Front-End desenvolvida com foco em escalabilidade, experiência do usuário e boas práticas de arquitetura.

Construída utilizando React e TypeScript, aplicando conceitos de componentização, separação de responsabilidades e manutenção de código em ambientes reais.

**React • TypeScript • Vite • React Router • ESLint**

---

## 📌 Sobre o Projeto

O Devyssey foi criado para simular a estrutura e os desafios encontrados em aplicações modernas de Front-End.

O objetivo é demonstrar a aplicação de boas práticas de desenvolvimento, organização de código e construção de interfaces preparadas para evolução contínua.

Feito com intuito de ajudar desenvolvedores em sua dia a dia no trabalho e também nos estudos.

### Principais objetivos

* Escalabilidade de código
* Componentização reutilizável
* Separação entre UI e lógica de negócio
* Manutenção simplificada
* Experiência consistente para o usuário

## 🏗️ Arquitetura

```bash
src
├── assets
├── components
│   ├── shared
│   └── ui
├── pages
├── routes
├── hooks
├── services
├── contexts
├── types
├── utils

```

Estrutura organizada para facilitar manutenção, reutilização e crescimento da aplicação.
